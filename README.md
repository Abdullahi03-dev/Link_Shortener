# Link Shortener

A simple and efficient **Link Shortener** web application built using React and Vite. This app allows users to shorten long URLs into compact, shareable links.

## Features

- **Shorten Long URLs**: Quickly convert long URLs into short, easy-to-share links.
- **Copy to Clipboard**: One-click copy of the shortened link.
- **Responsive Design**: Works smoothly on both desktop and mobile devices.
- **Fast Development Setup**: Powered by React and Vite for a fast and optimized development experience.
